# 💼 Job Board Web Application

A fully functional **Job Board Web App** that allows users to post, search, and apply for jobs — built with **HTML, CSS, JavaScript**, and **Firebase** (for backend and database).

---

## 🌐 Live Demo
👉 **[Click here to view the live project](https://job-board-web.vercel.app/)**

---

## 🚀 Features
- User authentication (Login / Register)
- Job posting and search functionality
- Real-time database using Firebase
- Responsive and modern UI design
- Clean and maintainable code structure

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Firebase (Authentication & Realtime Database)
- **Hosting:** Vercel
